# Netwizard 网络向导

## 集成信息

固件内置 `luci-app-netwizard`，用于在 LuCI 后台执行网络初始配置。插件源码已纳入仓库的 `package/luci-app-netwizard`，上游来源固定为提交 `7867a28e711269889ca1c999a0ce844c3adb45a0`；重新克隆源码并清理构建缓存后不需要额外拉取第三方 feed。

该插件使用上游自带的简体中文翻译，不需要单独选择 i18n 包。

## 使用范围与风险

该向导面向新设备或准备重新初始化网络的设备。仅安装固件、首次启动系统或打开其页面不会变更网络；在页面中保存并应用时，才会执行配置调整。

执行应用后，插件可能重建或修改以下系统配置：

- WAN、LAN 和 IPv6 接口；
- 防火墙区域、转发和 NAT；
- DHCP 与 DNS 选项；
- 无线网络参数；
- HTTPS、Web 服务相关配置。

因此，已有稳定网络配置的设备不应直接应用该向导。执行前应先导出系统备份，并确保可通过本地终端或控制台恢复。

## 服务管理

插件提供 `/etc/init.d/netwizard` 供 LuCI 应用提交配置时调用。该脚本的启动与重启会触发网络重配，故按项目约定不加入“系统 -> 服务”的统一服务管理页，也不会在首次启动时启用。

## 构建

本包没有额外的第三方 feed 或下载步骤。维护配置时，先将 `config-temp` 同步为 `.config`，再运行 `make defconfig`，最后执行完整固件构建：

```sh
make -j"$(nproc)" V=s
```
