# 云服务器首次初始化检查

> 编译机（云服务器）首次上电或系统重启后，需要进行以下初始化操作才能正常使用虚拟机。

## 1. 启动虚拟机

### 1.1 启动 libvirt 默认网络

虚拟机依赖 libvirt 的 `default` NAT 网络（`virbr0`，网段 `192.168.122.0/24`），首次启动前需确保该网络已激活。

```bash
sudo virsh net-start default
```

如需设置开机自动启动：

```bash
sudo virsh net-autostart default
```

### 1.2 启动虚拟机

```bash
sudo virsh start openwrt-vm
```

### 1.3 验证运行状态

```bash
# 查看所有虚拟机状态
sudo virsh list --all

# 测试网络连通性
ping -c 3 192.168.122.3
```

输出示例：

```
 Id   Name         State
----------------------------
 2    openwrt-vm   running
```

## 2. 配置端口转发

> 将宿主机端口映射到虚拟机端口，以实现外部直接访问 OpenWrt 服务（如 LuCI Web 管理界面）。

### 2.1 确认 IP 转发已开启

```bash
sysctl net.ipv4.ip_forward
```

应返回 `net.ipv4.ip_forward = 1`。若未开启：

```bash
sudo sysctl -w net.ipv4.ip_forward=1
echo "net.ipv4.ip_forward=1" | sudo tee -a /etc/sysctl.conf
```

### 2.2 添加 nftables 转发规则

本环境使用 nftables（`iptables-nft` 兼容层），以下规则将宿主机 `80` 端口流量 DNAT 到虚拟机 `192.168.122.3:80`。

**PREROUTING DNAT**（处理外部访问宿主机的流量）：

```bash
sudo nft add rule ip nat PREROUTING tcp dport 80 dnat to 192.168.122.3:80
```

**FORWARD ACCEPT**（允许转发到虚拟机，需置顶优先于 libvirt 过滤链）：

```bash
sudo nft add rule ip filter FORWARD ip daddr 192.168.122.3 tcp dport 80 accept
```

> 注意：该规则必须插入到 `FORWARD` 链的最前面（即 `position 0`），否则会被 `LIBVIRT_FWI` 链的 `reject` 规则拦截。

**OUTPUT DNAT**（处理宿主机自身访问本机 IP 的流量）：

```bash
sudo nft add rule ip nat OUTPUT tcp dport 80 ip daddr <宿主机IP> dnat to 192.168.122.3:80
```

将 `<宿主机IP>` 替换为宿主机实际 IP，可通过 `ip route | grep default` 查看。

### 2.3 验证端口转发

```bash
curl -s -o /dev/null -w "HTTP状态码: %{http_code}\n" http://<宿主机IP>:80
```

返回 `HTTP状态码: 200` 即表示转发正常。

### 2.4 持久化规则

保存当前 nftables 规则集，确保重启后自动恢复：

```bash
sudo nft list ruleset | sudo tee /etc/iptables/rules.v4 > /dev/null
```

> Ubuntu 使用 `netfilter-persistent` 服务在开机时自动加载 `/etc/iptables/rules.v4`。

## 3. 完整初始化脚本

以下是一个可一键执行的初始化脚本（保存为 `init-vm.sh` 上传到编译机后执行）：

```bash
#!/bin/bash
# 编译机首次初始化脚本
# 用法: bash init-vm.sh

HOST_IP=$(ip route | grep default | awk '{print $9}')

echo "[1/4] 启动 libvirt 默认网络..."
sudo virsh net-start default 2>/dev/null || echo "网络已启动"

echo "[2/4] 启动虚拟机 openwrt-vm..."
sudo virsh start openwrt-vm 2>/dev/null || echo "虚拟机已运行"

echo "[3/4] 配置端口转发 (80 → 192.168.122.3:80)..."
sudo nft add rule ip nat PREROUTING tcp dport 80 dnat to 192.168.122.3:80 2>/dev/null
sudo nft add rule ip filter FORWARD ip daddr 192.168.122.3 tcp dport 80 accept 2>/dev/null
sudo nft add rule ip nat OUTPUT tcp dport 80 ip daddr "$HOST_IP" dnat to 192.168.122.3:80 2>/dev/null

echo "[4/4] 持久化规则..."
sudo nft list ruleset | sudo tee /etc/iptables/rules.v4 > /dev/null

echo "完成！等待虚拟机启动..."
sleep 5
ping -c 2 192.168.122.3
curl -s -o /dev/null -w "端口转发测试: %{http_code}\n" "http://$HOST_IP:80"
```

## 4. 常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| `network 'default' is not active` | libvirt NAT 网络未启动 | 执行 `sudo virsh net-start default` |
| `Destination Host Unreachable` | 虚拟机尚未完全启动 | 等待几秒后重试 `ping 192.168.122.3` |
| 端口转发 `HTTP 000` | FORWARD 规则被 libvirt 过滤链拦截 | 确保 ACCEPT 规则位于 FORWARD 链最前面 |
